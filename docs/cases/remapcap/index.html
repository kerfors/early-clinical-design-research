REMAP-CAP: the documents

On this page: Core Protocol · Patient, Pathogen and Disease Appendix · Domain-specific appendices · Other current documents on remapcap.org (not read here) · Superseded versions listed on remapcap.org

REMAP-CAP is an adaptive platform trial in community-acquired pneumonia. Its protocol is a set of documents posted on remapcap.org: a Core Protocol, the Patient, Pathogen and Disease Appendix (PANDA), and one domain-specific appendix (DSA) per domain, plus region-specific and other appendices. All are public.

The documents read in this work: 12. Version and date as each document's page header states them (documents.csv, written by rcap_docs.py); listings as on remapcap.org when retrieved (manifest.csv, with sha256 per file).
